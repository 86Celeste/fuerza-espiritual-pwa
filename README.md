# Fuerza Espiritual PWA

Aplicación web progresiva para motivación, frases inspiradoras, respiración guiada, favoritos y afirmaciones personales.

## Requisitos
- Node.js 18+
- npm

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Abre la app en:
- http://localhost:3000

## Build para producción

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Deploy
Puedes desplegarlo en:
- Netlify
- Vercel
- GitHub Pages

## Nota
El logo base viene en `public/logo.svg`. Si quieres reemplazarlo por tu logo final, solo cambia ese archivo o agrega tu `logo.jpg` o `logo.png`.
